# Relato responsável

Envie suspeitas de vulnerabilidade pelo canal privado [suporte@komyst.com.br](mailto:suporte@komyst.com.br). Informe a versão, as condições observadas, o impacto e os passos de reprodução com dados de teste. Omita credenciais, códigos de licença e dados de terceiros. Aguarde a avaliação antes de divulgar o caso publicamente.

## English

Report vulnerabilities privately to [suporte@komyst.com.br](mailto:suporte@komyst.com.br). Include the version, observed conditions, impact and reproduction steps with test data. Omit credentials, license codes and third-party data. Allow time for an assessment before public disclosure.
