# Editorial workflow

[Português](../editorial-workflow.md) · [Home](../../README.en.md)

1. Keep the source pages and choose **Clean only** if your team will handle translation and lettering.
2. Choose **Complete** to review the processed page, cleaned artwork and PSD when those files are produced.
3. Compare the same region in the original, cleaned and typeset outputs. Check balloon borders, backgrounds, residual text, proper names, readability and overflow.
4. In the editorial PSD, inspect **ORIGINAL**, **CLEAN** and **TEXT**. Native type layers can be identified in the file structure. Fonts, effects and editing in Photoshop need verification with the specific file and editor.

The [public demo](../../samples/README.md#english) documents the artwork source and how the text was prepared. [See processing modes](https://komyst.com.br/motores.html).
